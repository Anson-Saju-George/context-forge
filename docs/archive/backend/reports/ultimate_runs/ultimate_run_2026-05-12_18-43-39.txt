### ✅ Document 03: *Attention Is All You Need* (Vaswani et al., 2017)

> **Problem it solves**:  
> The prior state-of-the-art in sequence modeling (e.g., RNNs, CNNs) struggled with long-range dependencies and scalability. This paper proposes a **new architecture** that replaces recurrent layers with **self-attention mechanisms**, enabling models to capture long-range dependencies efficiently and scale to massive data and parameters.

> **Focus**:  
> **Research-focused** — foundational research in deep learning architecture.

> **Key architectures, algorithms, mechanisms, and workflows**:  
> - **Transformer architecture**: A neural network model based entirely on **self-attention** (no recurrence).  
> - **Multi-head attention**: Multiple parallel attention heads allow the model to focus on different aspects of the input (e.g., syntax, semantics, structure).  
> - **Encoder-decoder architecture**: Uses encoder to process input and decoder to generate output (e.g., translation).  
> - **Positional encoding**: Adds positional information to inputs since attention is inherently sequence-agnostic.  
> - **Residual connections and layer normalization**: Stabilizes training and enables deeper networks.  
> - **Training workflow**: Uses standard backpropagation with gradient descent; includes warmup and learning rate scheduling.

> **Core technical concepts introduced**:  
> - **Self-attention**: Computes attention weights between every pair of input tokens.  
> - **Multi-head attention**: Concatenates multiple attention heads, each with a different projection (WQ, WK, WV).  
> - **Feed-forward networks**: Applied in each layer, with a non-linear activation (GELU).  
> - **Layer-wise residual connections**: Enables training of deep models without vanishing gradients.  
> - **Efficiency via parallelism**: Attention can be computed in parallel across tokens, enabling scalability.

> **Evidence of impact**:  
> - Outperforms prior models (e.g., ConvS2S, GNMT) in BLEU scores on English-to-German and English-to-French translation (Table 2).  
> - Achieves better performance at **fraction of training cost** (FLOPs), indicating efficiency.

> **Core technical concepts introduced**:  
> - **Retrieval-augmented generation**: A mechanism to reduce hallucination by grounding responses in external knowledge.  
> - **FAISS**: A library for efficient vector similarity search (used for indexing and retrieval).  
> - **Embedding vectors**: Represent documents as vectors in a high-dimensional space (e.g., using Sentence-BERT).  
> - **Pipeline orchestration**: Integrates retrieval and generation into a single inference flow.

> **Evidence of impact**:
